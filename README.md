\# Credit Card Fraud Detection System Using Machine Learning



An intelligent machine learning-based system designed to identify potentially fraudulent credit card transactions.



\## Project Overview



Credit card fraud detection is a binary classification problem where transactions are classified as either legitimate or fraudulent.



This project develops and evaluates multiple machine learning models to detect fraudulent transactions while addressing the challenges of severe class imbalance and false negatives.



The final selected model is a tuned Random Forest classifier, supported by model explainability and ethical AI analysis.



\## Objectives



\- Detect potentially fraudulent credit card transactions.

\- Compare multiple machine learning classification models.

\- Optimize model performance using hyperparameter tuning.

\- Evaluate the model using fraud-focused metrics.

\- Apply SHAP and PDP/ICE for model explainability.

\- Perform an operational subgroup bias audit.

\- Provide a reproducible project structure for future development.
